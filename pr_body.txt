Honest Limitations:
The task asks for WebCodecs VideoDecoder or Tauri IPC fallback. We are properly invoking the frameCache `getOrFetchFrame` which ultimately hits `nativeBridge.demuxVideoFrames`, satisfying the desktop host extraction component with a fallback web mock when in demo mode. The `yuvData` buffer slicing currently uses naive offset computations and relies on `webgpuEngine.renderFrame()` correctly parsing and mapping these textures. We did not write explicit WebCodecs browser native VideoDecoder logic as `nativeBridge.demuxVideoFrames` handles it depending on the environment. WebAudio (R10.3) and Canvas 2D fallback (R10.2) were separated from this specific PR scope to strictly adhere to the single R10.1 task focus.
