### Honest Limitations
The 2D fallback for YUV420p to RGB conversion uses a JavaScript loop directly on an `ImageData` array to perform color space conversion. While functional, it is CPU-intensive and unoptimized for real-time 4K rendering. Furthermore, applying WebGPU scale/rotate transformations in the 2D canvas ignores the drawn YUV pixels initially unless an offscreen canvas is introduced (which currently isn't to save performance). Therefore, spatial transforms may not be accurately reflected in the fallback mode. The goal was purely fallback visibility to avoid crashing.
