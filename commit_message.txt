feat(core): restrict demo mode to dev environments only (Task: R11.3)

Restricts the 'demo' runtime mode (a mock fallback mode used for UI
previews without a backend) to only activate during local development
(`import.meta.env.DEV`).

- Modified `src/services/runtimeConfig.ts` to log a warning and return
  early if `setRuntimeMode('demo')` is called in production.
- Conditionally hid the LIVE/DEMO toggle pill in `src/components/TopBar.tsx`
  so it is not presented to end users in a production release.
- Added test coverage in `src/__tests__/runtimeMode.test.ts` and
  `src/components/TopBar.test.tsx` to assert that demo mode cannot be set
  and the toggle is not rendered in production.
